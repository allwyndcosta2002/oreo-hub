# Oreo's Puppy Hub

A single-page puppy care hub for Oreo, a miniature Cavoodle: arrival checklist, 4th-floor safety prep, daily routine and the mid-January separation protocol, training and coat care, feeding calculator, toxic-food checker, vaccine/worming/tick tracker, weight log and notes.

- **Private by design:** everything you enter is saved in your own browser (localStorage) and never leaves the device. Use **Backup / Restore** to move data between phones.
- **Offline:** installable as an app (Chrome → ⋮ → Install app). A service worker caches the files.
- **Locked down:** no third-party scripts, fonts or trackers; a Content-Security-Policy only allows files from this site; restored backups are validated before use.

Hosted with GitHub Pages from the `main` branch root.

General guidance only; your vet's advice takes priority.
